# 让胡桃「有限地」碰你的电脑

默认情况下，胡桃只会聊天：她读不到文件、看不到屏幕、也起不了任何程序。
下面这些能力全部是**你自己一项一项打开**的，而且每一项都有独立的开关、白名单和上限。

## 五种能力

| 能力 | 打开后她能做什么 | 默认 |
| --- | --- | --- |
| 读文件 | 读白名单目录里的文本文件（txt/md/json/log/csv/代码等），单个文件上限 256KB | 关 |
| 列目录 | 列出白名单目录里的文件名、类型、大小，最多 200 条 | 关 |
| 看屏幕 | 截一张主屏，转成 PNG 交给模型看 | 关 |
| 开程序 | 只打开你自己登记的条目：程序、文件或网址 | 关 |
| 跑命令 | 生成 shell 命令，但**必须你在面板里点「允许」才会执行** | 关 |

写文件、删文件、改注册表这类操作没有对应工具——需要动文件时只能走「跑命令」，而且每次都要你确认。

## 三层闸门

1. **策略闸门**：`access-settings.json` 里的总开关与四个分开关，任何一项关着，对应工具根本不会出现在模型的工具列表里（不是被拒绝，而是模型看不见）。
2. **路径闸门**：读文件/列目录会先 `realpath` 再比对白名单目录，`..` 跳出、符号链接跳转都会被拦；`C:\Windows`、`C:\Program Files`、`C:\ProgramData`、`C:\$Recycle.Bin`、`AppData` 这类系统目录即使在白名单里也会被拒绝。
3. **审批与限流闸门**：命令必须先落进「等待确认」队列（2 分钟不处理自动过期），你点「允许」才真的跑；所有操作共享每小时上限（默认 30 次），超了就等下一小时。

## 面板怎么配

侧边栏第 5 个标签「权限」：

- **配置**：总开关、四个分开关、只读目录（每行一个绝对路径）、打开白名单（每行 `名字|路径或网址`）、每小时上限、命令超时。
- **等待确认**：命令排队时会出现在这里，点「允许」/「拒绝」。
- **审计**：最近几条操作记录（谁、做了什么、成没成），完整记录在 `userData/access-audit.jsonl`。
- **打开工作台**：见 [workbench.md](workbench.md)。

## QQ 里的边界

即使权限全部打开，群里也只有**管理员 QQ** 能指挥她动电脑：

- 面板里 `QQ` 标签 →「管理员 QQ（每行一个）」填你自己的号，默认是空的（谁都不能指挥）。
- 群里只有**管理员 @ 她**的那一句才会挂工具；插话、普通群友的 @ 都只聊天。
- 管理员私聊她可以直接下指令（「帮我看看 E:\Project\HuTao 里有什么」），她做完会用一句话回结果。
- 她做不到时会直说做不到，不会假装做过。

## 审计与撤回

- 每次操作（成功或失败）都会写一条审计，包含时间、发起方（`panel` / `qq:<QQ号>` / `workbench`）、动作、目标、结果。
- 觉得不对劲：把总开关关掉即可，工具立刻从模型侧消失；`access-audit.jsonl` 可以整份删除，删除后不影响运行。

## 文件位置

| 文件 | 内容 |
| --- | --- |
| `userData/access-settings.json` | 权限策略（开关、白名单、上限、工作台端口与 token） |
| `userData/access-audit.jsonl` | 审计日志（超过 1MB 轮转为 `.1`） |

## 已知边界

- 截图拿到的是主屏缩略图（长边约 1280），不是原分辨率，避免一次请求塞进几 MB 图片。
- 命令用 `powershell.exe -NoProfile -Command` 执行，输出截断到 4000 字符；交互式程序（如编辑器）不适合走这条路。
- 白名单目录以「目录」为单位，不支持通配符；想放宽就加目录，不建议直接加 `C:\`。
- 没有沙箱隔离：命令以你的用户身份运行，所以「允许」这个动作要你自己看清命令内容。
