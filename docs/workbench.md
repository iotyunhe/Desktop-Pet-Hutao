# 胡桃工作台

工作台是桌宠内置的一个**只在本机**的小网页：桌宠在主进程里起一个 HTTP 服务（只监听 `127.0.0.1`），你用浏览器打开它，就能在一个页面里看状态、批命令、配权限。

它不是第二套程序，关掉桌宠页面就打不开了。

## 三种打开方式

1. 托盘图标右键 →「胡桃工作台」。
2. 侧边栏「权限」标签 →「打开工作台」。
3. 命令行带参数启动：`胡桃桌宠.exe --open-workbench`。
   想常驻入口可以跑一次 `scripts/create-workbench-shortcut.ps1`，桌面会多一个「胡桃工作台」快捷方式。

第一次打开时桌宠会随机生成一个 token，地址形如：

```
http://127.0.0.1:4649/?t=1f3c...（32 位十六进制）
```

页面读到 token 后会立刻把它从地址栏抹掉，之后用 `x-hutao-token` 头访问接口。

## 页面上能做什么

| 区块 | 内容 |
| --- | --- |
| 顶部状态 | 版本、本机访问开没开、QQ 状态、当前模型、今天在群里说了几句 |
| 权限总开关 | 总开关与四个分开关、只读目录、打开白名单、每小时上限、命令超时 |
| 等待确认 | 她排队等审批的命令，一键允许/拒绝 |
| 审计记录 | 最近的操作记录，可一键清空 |
| 手动试试 | 读文件 / 列目录 / 截屏，直接看结果，用来验证白名单配得对不对 |
| QQ 群聊 | QQ 状态、刷新群列表、让她去逛 B 站、管理员 QQ |

所有按钮最终都落到桌宠的同一个权限内核上，页面本身没有额外权限。

## 端口与 token

- 默认端口 `4649`，被占用时会自动换一个空闲端口（最多试 10 次），实际地址以打开时的为准。
- 端口和 token 存在 `userData/access-settings.json` 的 `workbenchPort` / `workbenchToken`；想换端口直接改文件或重开页面。
- token 只在本机回环地址上有效，不要把它贴到聊天或截图里；泄露了就清空 `workbenchToken`，下次打开会重新生成。
- 服务拒绝一切没有 token 的请求（返回 401），也不监听外网地址。

## 改页面

页面在仓库 `tools/hutao-workbench/index.html`，是纯静态单文件（没有构建步骤、没有外部依赖）。
打包后会复制到安装目录的 `resources/workbench/index.html`，**改完直接刷新浏览器即可**，不用重新编译；想改样式或加按钮，改这个文件就行（接口见 `src/main/workbench/server.ts` 里的 `runAction`）。

## 关掉它

- 关掉桌宠，服务跟着停。
- 只想关网页：直接关标签页。
- 想彻底禁用工作台：把 `access-settings.json` 的 `workbenchPort` 改成别的已占用端口也行，但更简单的做法是——不开就不占用（服务只在第一次打开时才启动）。

## 已知边界

- 页面只在本机可用，手机或其他电脑访问不到（也不建议放开）。
- 服务不提供「退出桌宠」「卸载」这类破坏性操作，避免误点。
- 没有登录会话，token 就是唯一凭据；多人共用一台电脑时请自己注意。
