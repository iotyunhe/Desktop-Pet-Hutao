# 让胡桃进群聊天：QQ 板块配置指南

桌宠本身**不登录 QQ**。它在本机起一个 OneBot 11 反向 WebSocket 服务，由「协议端」把 QQ 的消息转发过来；胡桃决定要不要回、回什么，再用同一个连接把话发回去。

```
桌面 QQ（小号） ── 协议端 SnowLuma ──反向 WS──> 胡桃桌宠（127.0.0.1:6700）
```

这份指南只讲「怎么接上、怎么调得像个人」。协议端的详细安装（含 QQ 本体安装）见仓库外部教程或本文最后的排障一节。

---

## 0. 先说风险

- 第三方协议端（SnowLuma / NapCat 等）**不是腾讯官方方案**，违反 QQ 用户协议的条款，存在**被封号**的可能。
- 请**只用小号**，不要在用了多年、绑了支付/游戏资产的主号上跑。
- 频率控制是「更像人」也是「更安全」的关键：胡桃默认**每 10 分钟最多说 4 句**，同一个群说话后至少冷却 4 分钟。
- 只加你信任的群；胡桃默认**不主动私聊、不发链接、不加好友**。

如果只想要「官方合规、随时可停」的方案，可以改用 QQ 官方机器人平台（只能被 @ 才有反应，做不到自主插话）。

---

## 1. 准备

1. 一个小号（建议注册满 7 天以上，先正常用一段时间再上协议端）。
2. 本机安装**桌面版 QQ**（NT 版，官方安装包）。SnowLuma 是挂在桌面 QQ 上的，不在网页/手机端。
3. 下载 SnowLuma：<https://github.com/SnowLuma/SnowLuma> 的 `SnowLuma-v2.x.x-win-x64.zip`（自带运行时，解压即用）。

> 也支持 NapCat（`https://napneko.github.io`），它自带 QQ 安装，本指南以 SnowLuma 为例。两者对胡桃来说都是 OneBot 11，配置只需改端口与 token。

解压到固定目录，例如 `D:\SnowLuma\`。目录里应有 `SnowLuma.exe`、`config\`。

---

## 2. 登录小号

1. **先启动 SnowLuma**，再在打开的桌面 QQ 里登录小号（顺序不能反，反了 SnowLuma 认不到这个号）。
2. 首次运行会要求同意用户协议，并可能要求扫码/短信验证，按提示完成。
3. 登录成功后，SnowLuma 会生成 `config\onebot_<小号QQ>.json`。
4. 打开 SnowLuma 控制台地址 <http://127.0.0.1:5099>，确认账号在线。

---

## 3. 让 SnowLuma 连上胡桃

胡桃这边默认监听 `ws://127.0.0.1:6700/ws`，需要一个 token（随便设一串，但两边要一致）。

### 3.1 用脚本自动写配置（推荐）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\qq-setup.ps1 -Uin <小号QQ> -SnowLumaDir 'D:\SnowLuma'
```

脚本会：

- 生成一个随机 token，并写进 `config\onebot_<小号QQ>.json` 的 `network.websocketClients`（保留文件里其它配置，重复执行只会更新 `name=hutao` 那一条）；
- 把该用到的值打印出来，方便粘到桌宠面板里。

然后**重启 SnowLuma**（不需要退出 QQ），连接会自己建立。

### 3.2 手动改配置

编辑 `config\onebot_<小号QQ>.json`，在 `network.websocketClients` 里加一条：

```json
{
  "name": "hutao",
  "enable": true,
  "url": "ws://127.0.0.1:6700/ws",
  "messagePostFormat": "array",
  "reportSelfMessage": false,
  "reconnectInterval": 1000,
  "token": "你自己设的token",
  "debug": false,
  "heartInterval": 1000
}
```

保存后重启 SnowLuma。

---

## 4. 在桌宠里打开 QQ 板块

右键胡桃 → 打开面板 → **QQ** 标签：

| 项 | 说明 |
| --- | --- |
| 启用 | 关掉就断开连接，不卸任何东西 |
| 端口 | 默认 `6700`，要和配置里的 url 端口一致 |
| 小号 QQ | 填小号号码，用来避免胡桃回自己说的话 |
| token | 和 SnowLuma 配置里一致；两边的 token 不一致会一直「未连接」 |
| 监听地址 | 显示当前 `ws://127.0.0.1:<端口>/ws`，与配置核对 |

点「连接」后状态会变成「已连接」，并显示小号昵称。

### 群白名单

点「刷新群列表」会读出小号加入的全部群，点群名前面的方框加入白名单。**没加白名单的群，胡桃一句话都不会说**（连 @ 也不回）。

也可以手填群号（例如 `123456789`）后点「加入」。

### 说话规则

| 规则 | 默认 | 说明 |
| --- | --- | --- |
| @ 必回 | 开 | 群里 @ 胡桃，一定回，且不受频率限制 |
| 叫名字回 | 70% | 消息里出现「胡桃」，按这个概率回 |
| 主动插话 | 8% | 普通聊天时按这个概率插一句 |
| 插话冷却 | 4 分钟 | 同一个群刚说过话，这段内不再主动插话 |
| 10 分钟上限 | 4 条 | 滑动窗口内最多说这么多（@ 的回复不算） |
| 免打扰 | 开 | 01:00–08:00 谁叫都不应；「免打扰」勾选控制开关，时间可改 |

### 人设

「群聊人设」留空时用胡桃默认口吻（短句、口语、不写 Markdown、不承认自己是 AI）。写了会覆盖默认的补充描述，例如：

```
你是原神里的胡桃，往生堂第七十七代堂主。说话跳脱但温暖，喜欢开玩笑、偶尔用一点古风词，偶尔提「本堂主」，不用表情包符号。
```

---

## 5. 她到底怎么说话

- 先攒上下文：每个群保留最近 16 条消息，超过 10 分钟自动清空，避免拿着昨天的对话接今天的梗。
- 判断该不该说：@ → 必回；叫名字 → 按概率；普通聊天 → 冷却 + 概率 + 频率上限，任一不满足就安静。
- 生成内容：调你配置的大模型，限制 60 字左右。
- 发出去之前：
  - 打字延迟 ≈ `字数 × 95ms + 随机 0–900ms`，最长 4.6 秒，像在打字；
  - 太长会拆成 1–3 条，条与条之间 0.7–2.3 秒；
  - 自动去掉链接、@全体、Markdown 符号和 `think` 思考过程；
  - 模型调用失败时回一句固定的胡桃味台词，不会在群里卡住。
- 记仇：最近 12 条自己说过的话会列在面板里，方便你回看她在群里都说了什么。

---

## 6. 排障

| 现象 | 原因与处理 |
| --- | --- |
| 一直「未连接」 | token 不一致；端口被占用；SnowLuma 没重启；url 写成了 `ws://127.0.0.1:6700`（少了 `/ws`） |
| 连上了但读不到群 | 小号刚进群；点「刷新群列表」；SnowLuma 版本过旧不支持 `get_group_list` |
| 群里完全没反应 | 群不在白名单；「启用」没开；在免打扰时段；已触发频率上限（面板会显示今日已说 N 句） |
| 胡桃说话了但很怪 | 群聊人设写太长/太抽象；上下文被清空后她只看得到当前这一条 |
| QQ 自动升级后协议端失效 | SnowLuma/NapCat 需要等新版本重新挂钩；期间桌宠只是连不上，不影响本体 |
| 端口冲突 | 面板里把端口改成别的（如 6701），SnowLuma 配置里的 url 同步改 |

日志在 `%APPDATA%\hutao-desktop-pet\logs\app.log`，搜索 `qq` 可以看到连接、判定与发送记录（不含消息全文以外的隐私内容）。

---

## 7. 关闭与清理

- 只想临时停：面板里取消「启用」，或点「断开」。
- 彻底不用：删掉 SnowLuma 配置里的 `name: hutao` 那一条，并删掉 `%APPDATA%\hutao-desktop-pet\qq-settings.json`。
- 换小号：SnowLuma 里退出旧号登录新号，重新执行 `scripts\qq-setup.ps1 -Uin <新号>`，桌宠面板更新「小号 QQ」与群白名单。
